## About

python code for First Lego League (FLL) challenge 2025 unearthed. We are using pybricks for hub coding, more details about pybricks can be found at: [pybricks docs](https://docs.pybricks.com/en/latest/).

The `base_robot.py` and `utils.py` file was copied from [FLL-Team-24277](https://github.com/FLL-Team-24277/FLL-Fall-2025-Unearthed) with a few modifications to our needs.

Our design includes 6 attachments with 6 python files, the `runner.py` file allows selecting the program to run.
